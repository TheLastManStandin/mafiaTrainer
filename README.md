# Мафия · Практика

Тренажёр классической мафии для Linux x86_64 и браузера. Готовый исполняемый файл: **[dist/MafiaTrainer](dist/MafiaTrainer)**.

## Как открыть на телефоне

Подключи компьютер к точке доступа телефона или подключи оба устройства к одной сети Wi-Fi. Выполни эту команду в папке проекта на компьютере.

```bash
python3 main.py --web --host 0.0.0.0
```

Веб-версии достаточно Python 3.10 или новее. Сервер печатает адрес для телефона, например `http://172.20.10.3:8000`. Открой этот адрес в браузере телефона. На компьютере можно открыть `http://127.0.0.1:8000`. Если адрес телефона не напечатался, узнай адрес Wi-Fi компьютера командой `ip -4 -brief address` и подставь его вместе с портом `8000`.

Оставь терминал открытым на время тренировки. Сервер останавливается сочетанием **Ctrl+C**. Если порт занят, укажи другой, например `--port 8080`. Если страница на компьютере открывается, а на телефоне нет, проверь, что устройства в одной сети, а межсетевой экран компьютера и точка доступа пропускают соединения на выбранный порт.

Веб-версия запускается и из собранного бинарника командой `./dist/MafiaTrainer --web --host 0.0.0.0`.

В браузере доступны тренировки, подсказки, разборы, повтор ошибок, справочник, PDF и редактор вопросов. Веб-версия и оконная версия используют одну базу на компьютере. Для отдельной базы передай `--data-dir /путь/к/папке`. Результаты живут в открытой вкладке до новой тренировки или перезагрузки страницы. Устройства, которые могут открыть адрес сервера, также могут менять базу.

## Запуск оконной версии

Открой `dist/MafiaTrainer` двойным щелчком. Если файловый менеджер требует разрешить запуск, включи «Разрешить выполнение файла как программы» в свойствах файла. Через терминал из этой папки:

```bash
./dist/MafiaTrainer
```

Бинарник содержит Python, Qt, базу и учебные материалы. Устанавливать Python и библиотеки для его запуска не нужно. Сборка проверена на Ubuntu 22.04 x86_64 (glibc 2.35); предназначена для обычного графического сеанса Linux. Совместимость со всеми дистрибутивами не проверялась.

## Что внутри

- 180 заданий: 60 лёгких, 60 средних, 60 сложных.
- 8 выбираемых тем: жесты, роли, дневная игра, голосование, ночь, фолы и этика, особые случаи, логика и тактика. Каждая тема представлена на каждом уровне.
- На лёгком уровне — тесты; на среднем и сложном — короткие ответы и разборы с самооценкой.
- 60 заданий о жестах и терминах, из них 36 с исходными медиа MSU Mafia: 13 фотографий и 23 анимации. Недоступные видео заменены текстовыми задачами о значении; неоднозначные кадры движения не используются для угадывания жеста.
- Объяснение и источник после каждого ответа. У вопросов по правилам указан номер страницы PDF.
- Справочник с поиском, повтор ошибок, подсказки, итог по темам, схемы стола для части задач.
- Добавление своего вопроса перед игрой: уровень, темы, формат, варианты ответа, синонимы, объяснение, источник, изображение или GIF.
- Удаление вопроса во время игры. Можно сразу отменить последнее удаление либо позднее восстановить любой удалённый вопрос в «Моей базе».

Тренировки идут без таймера. Вопросы перемешиваются, не повторяются в пределах одной сессии, темы распределяются примерно равномерно. Если выбранных заданий меньше запрошенного количества, используются все доступные без повторов.

Клавиши **1–4** выбирают вариант теста. **Ctrl+Enter** проверяет ответ или переходит к следующему вопросу после разбора. В текстовых полях цифры вводятся обычным образом.

Короткие ответы учитывают регистр, пунктуацию, «е/ё» и заданные синонимы. Они не оцениваются внешней нейросетью. Если правильная формулировка не распознана, после сравнения с объяснением можно нажать «Мой ответ верный по смыслу»; это отмечается как ручной зачёт. Для тактики покажи свой ход мысли, прочитай разбор и выбери «Разобрался» или «Нужно повторить». Эти задания учитываются отдельно от автоматически проверяемых.

## Что сохраняется

**Результаты тренировок не записываются на диск.** Последнюю сессию можно посмотреть до начала новой; после закрытия приложения она исчезнет.

**Свои вопросы и удаления сохраняются**, иначе редактирование базы теряло бы смысл после перезапуска. По умолчанию это:

```text
~/.local/share/mafia-trainer/library.json
~/.local/share/mafia-trainer/media/
```

При установленном `XDG_DATA_HOME` используется `$XDG_DATA_HOME/mafia-trainer/`. Прикреплённые изображения копируются туда, поэтому исходный файл можно переместить. Встроенная база внутри бинарника остаётся целой: удаление хранится отдельной отметкой и обратимо.

Интернет для тренировок не требуется. Кнопка открытия внешнего источника использует браузер; PDF правил встроен и открывается локально.

## Источники

- Предоставленный документ `Классика Школа 21.pdf`: основной регламент; копия включена в `mafia_trainer/assets/rules.pdf`. Учитываются именно особенности этой редакции, а не предполагаемый универсальный регламент.
- [MSU Mafia — Словарь по жестикуляции](https://vk.ru/@msu.mafia-dictionary), 2022: фотографии, движения, значения жестов и примеры договорок. Объяснения и задания сформулированы для тренажёра. Правила из статьи не подменяют регламент PDF, если они отличаются.
- Логические и тактические задачи составлены для тренажёра. Условия о достоверности ролей и количестве мафии задаются явно. Предположения и заявления игроков отделены от подтверждённых фактов.

## Исходный код и сборка

- `mafia_trainer/core.py` — база, проверка ответов, выбор заданий, сессия и сохранение правок.
- `mafia_trainer/ui.py` — оконный интерфейс PySide6.
- `mafia_trainer/web.py` и `mafia_trainer/web_assets/` — веб-сервер и адаптивный интерфейс.
- `mafia_trainer/assets/questions.json` — готовая база.
- `tools/build_questions.py` — авторские задания и сборка базы из зафиксированного манифеста.
- `tools/gesture_manifest.json` — исходные адреса и названия материалов VK.
- `tests/` — проверки логики, сохранения правок, интерфейса и декодирования анимаций.

Для разработки использован Python 3.10. База и медиа уже включены в исходники, повторно скачивать их не требуется.

```bash
/usr/bin/python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python main.py
```

Сборка одним файлом с предварительным запуском тестов:

```bash
./build.sh
```

Проверка готового бинарника без видимых окон, с отдельной временной базой и снимками экранов:

```bash
QT_QPA_PLATFORM=offscreen ./dist/MafiaTrainer --smoke-test /tmp/mafia-check
```

Обычный запуск не создаёт тестовых вопросов, файлов снимков или диагностических сессий.
