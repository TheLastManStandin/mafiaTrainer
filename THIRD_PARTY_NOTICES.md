# Использованные компоненты и материалы

Интерфейс: PySide6 / Qt 6.8.3, The Qt Company. Проект использует динамические библиотеки из официальных пакетов PySide6. Сведения о лицензировании и исходном коде: https://doc.qt.io/qtforpython-6/licenses.html и https://download.qt.io/official_releases/QtForPython/pyside6/ .

Интерпретатор: Python 3.10, Python Software Foundation, https://www.python.org/psf/license/ .

Упаковка: PyInstaller, https://pyinstaller.org/ .

Учебные фотографии и исходные анимации: MSU Mafia, «Словарь по жестикуляции», 2022, https://vk.ru/@msu.mafia-dictionary . Анимации перекодированы из исходных коротких видео в GIF без изменения содержания движения. Материалы включены для личного обучения по ссылке пользователя; авторство сохранено в приложении и базе заданий.

Регламент: предоставленный пользователем документ «Классика Школа 21.pdf». Оригинал не изменён.
